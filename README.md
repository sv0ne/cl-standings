# Champions League Standings

Веб-приложение для просмотра турнира Лиги чемпионов УЕФА: таблицы общего этапа, результатов и расписания матчей, а также сетки плей-офф. Можно переключать сезоны и светлую/тёмную тему. В таблице отображаются статистика и результаты команд по турам; плей-офф показывает пары и счёт матчей.

## Данные и логика

Клиент загружает данные через внутренний маршрут `GET /api/standings?season=<год>`. Сервер обращается к Football-data.org API за таблицей и матчами, используя ключ API, и кеширует ответ. Данные текущего сезона обновляются с интервалом 60 секунд; для завершённых сезонов кеш не переобновляется. Для текущего сезона к ответу также добавляются правила и варианты сетки из `app/api/standings/champions-league-bracket.json`.

Список доступных сезонов задаётся в `app/site-config.ts`. Главная страница перенаправляет на `/champions-league/table`.

## Требования

- Node.js, совместимый с Next.js 15
- API-ключ Football-data.org

## Установка и запуск

```bash
npm install
```

Создайте `.env.local` в корне проекта и добавьте ключ:

```env
FOOTBALL_DATA_API_KEY=ваш_api_ключ
```

Запустите локальный сервер разработки:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Для production-сборки и локального запуска:

```bash
npm run build
npm run start
```
